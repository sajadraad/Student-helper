## 🚀 Quick Start

### 1. Prerequisites

- Python 3.11 or higher
- Telegram Bot Token (from [@BotFather](https://t.me/botfather))
- Google Gemini API Key

### 2. Installation

```bash
# Clone or download the project files
git clone <repository-url>
cd rezecoach

# Install dependencies
pip install -r requirements.txt

# Set environment variables
export TELEGRAM_BOT_TOKEN='your_telegram_bot_token'
export GEMINAI_API_KEY='your_gemini_api_key'
```

### 3. Run the Bot

```bash
python app.py
```

The bot will:
- ✅ Initialize the SQLite database
- ✅ Start the Telegram bot polling
- ✅ Launch the job scheduler for proactive features
- ✅ Begin accepting user interactions

## 📱 User Commands

### 🏁 Getting Started
- `/start` - Complete onboarding setup
- `/help` - View all available commands
- `/profile` - Display user profile

### 📚 Study Management
- `/addsubject <name> [priority]` - Add new subject
- `/subjects` - List all subjects
- `/setprogress <subject> <section>` - Update progress
- `/startsession [subject]` - Begin study session
- `/endsession` - End session with summary and rating

### 💧 Health Tracking
- `/water [cups]` - Log water intake
- `/waterlog` - View today's hydration

### 📅 Schedule & Planning
- `/setschedule` - Configure weekly schedule
- `/today` - View today's agenda
- `/stats` - Weekly performance statistics

### ⚙️ Settings
- `/settime <HH:MM>` - Daily reminder time
- `/timezone <zone>` - Set timezone
- `/toggleproactive <on|off>` - Control automatic messages

### 📤 Data Management
- `/export` - Download personal data backup
- `/reset` - Reset all data (with confirmation)

## 🏗️ Architecture

### Core Components

```
rezecoach/
├── app.py          # Main bot coordinator
├── db.py           # SQLite database management
├── ai.py           # Google Gemini AI integration
├── handlers.py     # Telegram message handlers
├── jobs.py         # Scheduled & event-driven jobs
├── utils.py        # Utility functions & helpers
├── schema.sql      # Database schema
├── requirements.txt
└── README.md
```

### Database Schema

- **users** - Profile, preferences, settings
- **subjects** - Study subjects with progress tracking
- **study_sessions** - Session timing and evaluations
- **water_logs** - Daily hydration tracking
- **weekly_schedule** - Class schedules and events
- **user_activity** - Behavior tracking for adaptation
- **files** - Uploaded documents and extracted text

### AI Integration

The bot uses **Google Gemini 2.5 Flash** for:
- 🌅 **Morning greetings** with personalized agendas
- 📝 **Note summarization** and flashcard generation
- 🌙 **Evening recaps** with study insights
- 📊 **Weekly evaluations** with strengths/weaknesses
- 💬 **Adaptive responses** to user messages
- 🎯 **Study plan generation** for subjects

### Proactive Features

**Scheduled Jobs:**
- Morning check-ins at user's preferred time
- Post-class follow-ups 60 minutes after classes
- Hydration reminders for users with low water intake
- Evening study recaps with AI-generated insights
- Weekly performance evaluations on Sundays

**Event-Driven Triggers:**
- Contextual responses to keywords ("رجعت البيت", "تعبان", etc.)

## 🚨 Troubleshooting

### Common Issues

**Bot not responding:**
```bash
# Check environment variables
echo $TELEGRAM_BOT_TOKEN
echo $GEMINAI_API_KEY

# Verify bot token
curl -s "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/getMe"
```

**Database errors:**
```bash
# Check database file permissions
ls -la rezecoach.db

# Recreate database
rm rezecoach.db
python -c "from db import DatabaseManager; DatabaseManager()"
```

**AI responses not working:**
```bash
# Test Gemini API
python -c "from ai import GeminiAI; ai = GeminiAI(); print('AI working')"
```

### Logging
All activities are logged to:
- Console output for real-time monitoring
- `rezecoach.log` file for persistent logging
- Different log levels: INFO, WARNING, ERROR
